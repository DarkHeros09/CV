# 📄 CV Website

Personal CV / portfolio website for **Mohammed Najib Benghuzzi**.

🔗 [mnb-cv.ly](https://mnb-cv.ly) — Built with **Go · Templ · UnoCSS · Alpine.js**, deployed via [GitHub Pages](https://mnbenghuzzi.github.io).

## 🛠 Tech Stack

| Layer | Technology |
|-------|-----------|
| Server | 🐹 Go 1.26 + [Fiber v3](https://docs.gofiber.io/) |
| Templates | 📝 [Templ](https://templ.guide/) — type-safe HTML templating |
| CSS | 🎨 [UnoCSS](https://unocss.dev/) — atomic CSS from `.templ` files |
| Interactivity | ⚡ [Alpine.js](https://alpinejs.dev/) — light/dark mode, cert modal |
| Dev Server | 🔄 [Air](https://github.com/air-verse/air) — live reload |


## 🚀 Getting Started

### Prerequisites

- **Go** `>= 1.26`
- **Node.js** `>= 18` (for UnoCSS)
- **Git**

### Install

```bash
make install
```

This installs Go dependencies (`go mod tidy`) and global tools:
- `templ` — Templ template compiler
- `unocss` — UnoCSS CLI
- `air` — Live reload server

For a fresh clone, use `make setup` to create the project structure + install everything.

### Development

```bash
make dev
```

Starts the development server at `http://localhost:3000` with live reload. 
Watches `.go`, `.templ`, and `.ts` files — rebuilds on every change.

### Build

```bash
make build
```

Generates CSS from UnoCSS, compiles `.templ` → Go code, then builds the binary to `tmp/main.exe`.

### Preview Build

```bash
make run
```

Builds and starts the server once (no live reload).

### Generate Static Site

```bash
make dist
```

Produces a fully static site in the `dist/` folder. Deploy this to any static host.

### Clean

```bash
make clean
```

Removes `tmp/` and `dist/` directories.

## 🚢 Deployment

The site is deployed to **GitHub Pages** via GitHub Actions (`.github/workflows/static.yml`).

On push to `main`, the workflow:
1. Installs Go + Node + `templ` + `unocss`
2. Generates CSS and templates
3. Runs `go run ./cmd/generate` → produces `dist/`
4. Uploads `dist/` to GitHub Pages

## ✏️ Customizing

### Edit CV Content

All personal data lives in `utils/cv_data.go`:
- Profile info (name, title, bio, links)
- Work experience
- Skills grouped by category
- Education / certifications

### Add a New Section

1. Add the data struct in `model/models.go`
2. Add the content in `utils/cv_data.go`
3. Create a `.templ` component in `view/homepage/`
4. Include it in `view/homepage/homepage.templ`

### Theme Colors

Edit CSS custom properties in `uno.config.ts` → `preflights` for light/dark color schemes.
